# 论文工作目录

本目录预留论文与投稿材料的维护位置。当前没有正文、选定模板或编译入口；格式与章节组织待确认。

| 子目录 | 用途 |
| --- | --- |
| `data/` | 论文图表采用的导出数据与来源清单，不替代实验原始证据 |
| `figures/` | 论文图片及可编辑图源 |
| `references/` | 引文库与必要的引用核验材料 |
| `template/` | 后续选定的投稿模板及使用说明 |
| `scripts/` | 论文素材导出、重绘与核验工具 |
| `build/` | 可重新生成的编译中间文件 |
| `qa/` | 内容、公式、引用和版面核验记录与渲染产物 |
| `archive/` | 有保留意义的历史稿件与修订前版本 |

后续确定唯一正文维护入口并在本文件登记。图表须追溯至[实验输出](../outputs/README.md)或明确的外部来源，检查坐标轴、单位、指标和引用；排版交付检查最终渲染结果，不只检查编译退出码。

现有征稿材料仍保留在项目根目录：[cfp_lawn.pdf](../cfp_lawn.pdf)。
