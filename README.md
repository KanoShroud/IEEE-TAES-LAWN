# IEEE TAES LAWN

本目录用于维护 IEEE TAES 低空无线网络特刊相关研究。当前首选方向为运动 UAV 网络中强弱混合辐射源的共享时频偏差校准与直接定位，处于文献与总体方案阶段。

研究入口：[低空辐射源被动定位：文献综述与总体方案设计](低空辐射源被动定位_文献综述与总体方案设计.md)。已读取 [CFP](cfp_lawn.pdf)，其列示投稿截止日期为 2027-02-28；投稿前需再次核对官方要求。

两批 L034—L048 已完成全文精读与 Zotero 分级（核心 7、重要支撑 5、条件补充 3）；[逐篇精读与方案更新](docs/15篇文献全文精读与方案更新_20261019.md)记录模型、算法、理论、实验条件及最新研究判断。
