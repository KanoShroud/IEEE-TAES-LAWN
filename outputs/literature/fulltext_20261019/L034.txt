Source Localization Using TDOA and FDOA
Measurements in the Presence of Receiver
Location Errors: Analysis and Solution
K. C. Ho, Senior Member, IEEE, Xiaoning Lu, Student Member, IEEE, and L. Kovavisaruch, Member, IEEE
Abstract—The accuracy of a source location estimate is very
sensitive to the accurate knowledge of receiver locations. This
paper performs analysis and develops a solution for locating
a moving source using time-difference-of-arrival (TDOA) and
frequency-difference-of-arrival (FDOA) measurements in the
presence of random errors in receiver locations. The anal-
ysis starts with the Cramér–Rao lower bound (CRLB) for the
problem, and derives the increase in mean-square error (MSE) in
source location estimate if the receiver locations are assumed cor-
rect but in fact have error. A solution is then proposed that takes
the receiver error into account to reduce the estimation error,
and it is shown analytically, under some mild approximations, to
achieve the CRLB accuracy for far-ﬁeld sources. The proposed
solution is closed form, computationally efﬁcient, and does not
have divergence problem as in iterative techniques. Simulations
corroborate the theoretical results and the good performance of
the proposed method.
Index Terms—Frequency difference of arrival (FDOA), receiver
location uncertainty, source localization, time difference of arrival
(TDOA).
I. INTRODUCTION
S
OURCE localization is a classical problem in radar and
sonar [1], [2]. Recently, there has been renewed interest
in this research, mainly driven by the emergency 911 location
ability imposed to wireless services [3], [4] as well as sensor
network applications [5]. Source localization can be based on
time-of-arrival (TOA), time-difference-of-arrival (TDOA), or
angle-of-arrival (AOA) measurements, or a combination of
them. When the source and/or receivers are moving, frequency
differences of arrival (FDOAs) can also be exploited to improve
location accuracy [6]. This paper focuses on TDOA localization
for a stationary source, and TDOA and FDOA localization for
a moving source.
Source localization is a nontrivial problem because the mea-
surements are nonlinearly related to the source location param-
eters. Over the years, many algorithms have been proposed for

and the closed-form solution methods [6], [8]–[20]. The closed-
form solution is attractive because it does not require initial so-
lution guesses and does not have divergence problem as com-
pared to the iterative techniques. Regardless of the localization
algorithms used, the source location accuracy can be very sen-
sitive to the accurate knowledge of the receiver positions and

error in source location estimate.
In practice, the receiver locations may not be known exactly.
For instance, in sensor network applications, the sensor nodes
are deployed randomly whose exact positions are often not
available. In modern localization applications, the receivers can
be airplanes or unmanned aerial vehicles (UAVs) [21] whose
positions and velocities may not be precisely known. As a
result, the inaccuracy in receiver locations needs to be taken
into account in practical environments.
The performance degradation created by receiver location
uncertainty has been known for a while in direction-of-arrival
(DOA) estimation. Rockah and Schultheiss [22], [23] improved
the DOA estimation accuracy in the presence of sensor position
error through array shape calibration using several sources
of unknown locations. Tseng et al. [24] proposed the projec-
tion-rotation-scaling (PROS) method to estimate the steering
vector in uncalibrated arrays, which is used to improve the
source DOA estimates. Viberg and Swindlehurst [25] proposed
the maximum a posteriori noise subspace ﬁtting (MAP-NSF)
method to reduce DOA estimation errors when receiving sensor
positions have uncertainty. Chen et al. [26] used the Toeplitz
approximation to ﬁnd the AOA in the presence of sensor posi-
tion errors. These methods are for estimating DOA of the source
only, rather than locating the source in a unique coordinate
point. Furthermore, the receivers and sources are assumed sta-
tionary. This paper addresses the problem of locating in unique
coordinates the position and velocity of an emitting source in
the presence of random receiver location errors. A recent work
by Jakoby et al. [27] examines the accuracy of joint source and
sensor location estimation through Cramér–Rao lower bound
(CRLB) for locating a stationary source in shallow water, but
no explicit estimation algorithm is given.
The purpose of the paper is twofold. First, it provides the
analysis of how much degradation the source location accu-
racy is with respect to the amount of receiver location errors.
Second, it proposes an explicit closed-form solution to the lo-
cation problem to improve the estimation accuracy. The anal-
ysis begins with the CRLB and examines the increase in CRLB

IV. CLOSED-FORM SOLUTION
It is well known that the maximum-likelihood (ML) estimate
can achieve the CRLB accuracy. Because of the nonlinear rela-
tionship between the measurements and the source location, ML
estimation requires numerical grid search which is time con-
suming. Gradient based iterative technique through lineariza-
tion such as Taylor-series method can be used instead of grid
search. Iterative technique requires good initial guesses close
to the true solution and could suffer from divergence problem.
Most importantly, both approaches require the estimation of re-
ceiver locations in conjunction with the source location in order
to reach the CRLB accuracy, although only the source location
is of interest.
In practice, the number of receivers can be large. Let us con-
sider a moderate value of
as an example. Instead of esti-
mating six parameters for the source, an additional
36 pa-
rameters for the receivers are also needed to be estimated. This
will make numerical grid search very difﬁcult, if not impossible,
in such a high-dimensional space, or big numerical linearization
error and possibly singularity problem in Taylor-series iterative
method. We shall propose here a closed-form solution to the
estimation problem. The interesting aspect of the proposed so-
lution is that it estimates only the source location parameters.
Most importantly, it can achieve the CRLB accuracy. We shall
ﬁrst describe the proposed solution, then an analysis will follow
together with a proof that the solution accuracy reaches CRLB
for far-ﬁeld source.

VI. CONCLUSION
Source localization using TDOA and FDOA measurements
require very precise knowledge of the receiver locations. A
small error in the receiver locations can lead to a signiﬁcant
decrease in source location accuracy, especially under poor lo-
cation geometry [large geometric dilution of precision (GDOP)]
and far-ﬁeld source scenarios. We have derived analytically the
increase in CRLB due to random and Gaussian receiver location
noise, and the increase in location MSE when an algorithm
assumes receiver locations are accurate but in fact have errors.
To minimize the effect of receiver error, we developed an al-
gebraic solution to improve the source location estimate. The
proposed solution is closed form, computationally attractive,
and not iterative. The solution accuracy is shown theoretically,
under some mild approximations, and verify by simulations to
attain the CRLB for far-ﬁeld source and Gaussian noise.
