Semideﬁnite Programming Methods for Alleviating
Clock Synchronization Bias and Sensor Position
Errors in TDOA Localization
Yanbin Zou
, Member, IEEE, and Huaping Liu
, Senior Member, IEEE
Abstract—This paper investigates the problem of source localiza-
tion using signal time-difference-of-arrival (TDOA) measurements
in the presence of clock synchronization bias and sensor position
errors. Our existing work has developed a uniﬁed solution for
TDOA localization in the presence of sensor position errors but
clock synchronization bias was not considered. Clock synchro-
nization bias is a more complex problem often encountered in
practical localization networks. This paper further generalizes this
framework to include clock synchronization bias. The proposed
technique employs multiple calibration emitters to simultaneously
alleviate both the sensor position errors and clock synchronization
bias. The maximum likelihood estimator (MLE) for this problem
is optimal, but too complex to be applied in practice. We develop
a semideﬁnite programming (SDP) based localization algorithm to
effectively solve the MLE problem. This SDP algorithm can reach
the Cram´er-Rao lower bound when sensor position errors are not
unrealistically large.
Index Terms—Calibration emitter, clock synchronization bias,
sensor position errors, source localization, time-difference-of-
arrival (TDOA).
I. INTRODUCTION
S
OURCE position information has many important applica-
tions, such as wireless sensor networks (WSN), asset track-
ing, mobile advertising, and emergency assistance [1]. Com-
monly positioning schemes include those that use the received
signal strength (RSS), time-of-arrival (TOA), time-difference-
of-arrival (TDOA) and angle-of-arrival (AOA) information.
TDOA systems require that the anchor nodes be clock syn-
chronized. However, synchronization is not a trivial issue, espe-
cially when the number of nodes is large and widely separated.
In the work reported in [2]–[4], nodes are divided into groups;
nodes in the same group are time-synchronized while nodes in
different groups are not.

Another challenging issue for TDOA localization is sensor
position errors, which could drastically degrade the accuracy.
Several literatures have addressed this problem [5]–[10], which
have shown that using calibration emitters could improve the
localizationperformance.Ourexistingworkin[9]hasdeveloped
a uniﬁed solution for TDOA localization in the presence of
sensor position errors but clock synchronization bias was not
considered.Mostpracticallocalizationnetworkshavebothclock
synchronization bias and sensor position errors that should be
dealt with jointly, which is the main goal of this paper.
The rest of this paper is organized as follows. Section II
gives the problem formulation. The proposed SDP algorithm is
derived in detail in Section III. Simulation results are presented
in Section IV to compare the performances of the proposed
algorithm and Cram´er-Rao lower bound (CRLB).

IV. SIMULATION RESULTS
A network with six sensors, one source and two calibra-
tion emitters is simulated. The unknown true positions of
the sensors are [3, 3]T m, [10, 3]T m, [12, 10]T m, [10, 17]T m,
[3, 17]T m, [0, 10]T m. The locations of two calibration emitters
are at [3, 10]T m and [8, 13]T m, and the location of source is at
[9, 7]T m. The clock synchronization bias Δti are drawn from
independent identically uniform distributions U[0, 1] μs. Both
sensors‘ position covariance matrice and calibration emitters’
position covariance matrice are δ2I2. The RDOA measurement
covariance matrices Qn = Qc = σ2R, where the diagonal ele-
mentsofmatrixRareallequalto1andtheoff-diagonalelements
of R areall equal to0.5[7]. Threepenaltyfactorsη1, η2, η3 equal
to 10−2, 10−1, 100, respectively. Each simulation generates 1000
Monte Carlo realizations.

V. CONCLUSION
An SDP-based algorithm for TDOA source localization in
the presence of clock synchronization bias and sensor position
errors is proposed in this paper. The clock synchronization bias
in TDOA measurements make the localization problem hard
to tackle. We consider using calibration emitters to alleviate
the clock synchronization bias and sensor position errors. The
nonconvex MLE problem is transformed into convex optimiza-
tion problem. Simulation results validate the performance of the
proposed algorithm.
