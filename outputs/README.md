# 输出目录

| 子目录 | 用途 |
| --- | --- |
| `experiments/` | 实验配置、日志、结果和必要的模型产物 |
| `reports/` | 结果分析、诊断和报告导出 |
| `verification/` | 静态检查、冒烟及工程验收产物 |

当前仅建立空目录。后续每次运行使用可区分的新目录，记录输入身份、配置和来源；不覆盖既有证据，保留失败尝试。

正式实验事实维护在[实验结果记录](../实验结果记录.md)，工程修改与验证维护在[修改记录](../修改记录.md)。论文使用的导出材料放入 [paper/](../paper/README.md)，并保留到原始证据的追溯关系。
